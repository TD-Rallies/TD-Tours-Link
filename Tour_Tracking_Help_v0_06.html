Tracking guide

Tracking — Live Tracking and Event Replay

The Tracking page shows entrant positions during the Tour, whether or not a suggested route has been mapped. Tracking devices normally report at approximately 30-second intervals, (Traccar 500 metres) subject to connectivity and device operation. It has two clear operating modes: Live Tracking for the current event and Event Replay for reviewing positions already stored in the Google Tracking sheet.

Tracking event upload

Upload required: Tracking must be uploaded before Live Tracking or Event Replay can operate.

Tracking does not require a mapped route or suggested route track. To use Tracking, the event needs the entrants to be tracked and the Tour dates on which Tracking is available.

Select Upload tracking data to send these details to the separate Tracking Google connection. Mapped route data can be included when available, but it is not required for entrant position tracking.

Rest days: Tracking is not enabled on rest days. Rest days are omitted from the Tour tracking dates, so the mobile tracker cannot start Tracking on those dates.

Live Tracking

Live Tracking reads the latest accepted position for each entrant from the separate Tracking Google connection. The page refreshes the live positions at regular intervals and keeps the map focused on the current Tour or selected entrant.

Live positions are last known positions. A delayed or stale marker means that a newer report has not yet been received; it does not prove that the entrant has stopped.

Entrant card and trail

The entrant card shows Tour number, entrant name, current tracking status, latest speed, and reported GPS accuracy. Trail choices are None, 5 min, 10 min, and All. Closing the card clears the selected state.

Centre map control

Select ◎ to restore the appropriate map view: the full Tour or the selected entrant. Tracking does not use rally control locations.

Event Replay

Select Event Replay to leave Live Tracking and review the recorded positions stored in the Google Tracking sheet. Replay and Live Tracking are separate modes; replay positions are never mixed with current live positions.

For an earlier Tour, open the corresponding saved Tour project. In Event Replay, select the date of the recorded Tracking run from the available history. Event Replay uses that project date to find the matching GPS history in Google.

Replay uses the stored GPS Time. It does not use Received Time, Tour-number order, or invented movement between records.

Choose what to replay

  • All entrants replays every entrant that has matching recorded history.
  • One entrant focuses on that entrant while retaining the normal entrant display behaviour.
  • The card shows the available recorded history range.
  • Select the required start time within that range.

Replay speed

Choose 1×, 2×, 5×, or 20×. The default is 1×. While Replay mode is open, the quick speed buttons beside the REPLAY indicator change speed immediately without restarting the replay.

Replay controls

  • Start / Pause starts the replay or freezes it at the exact current replay time.
  • Stop freezes the current replay for inspection.
  • Reset returns to the selected entrant, selected start time, and selected speed so the same selection can be replayed again.
  • Return to Live cancels Replay mode, clears replay-only display, fetches the latest positions, and resumes normal Live Tracking.

How recorded positions move

The page reads the available history when Replay is opened, then runs the replay locally in the browser. Each marker changes when its next stored GPS timestamp is reached.

  • Records with the same or very close GPS timestamps appear to move together.
  • Different timestamps produce the corresponding staggered movement.
  • If a record is missing, the entrant remains at the last recorded position.
  • There is no bridging, interpolation, or invented movement between Sheet records.
  • Delayed uploads still appear at their correct historical GPS time.

The winking REPLAY indicator shows that Replay is running. It remains visible but steady when replay is paused or stopped, and disappears on Return to Live.

Tour Apps — sharing and setup

The Dashboard's Tour Apps section provides links to the supporting apps. Select the required app and share its link by Copy, Email or WhatsApp.

New Tour, new link: The organiser must share the tracking link for each new Tour. Already-installed apps can be reused: opening the new link updates the app with the current Tour configuration, without reinstalling it. Each entrant enters their Tour number and surname for the current Tour.

Traccar — Android and iOS

Traccar provides background location tracking while the device is being used for other tasks or the screen is off. Initial setup involves more steps.

  1. Download and install Traccar from the device's application store.
  2. Set Location: Highest; Distance: 500 metres; Interval: 30 seconds; Angle: Disabled / 0 degrees; Stationary heartbeat: 60 seconds.
  3. Open the current Tour link shared by the organiser to apply the event configuration.
  4. Enter the Tour number and surname and turn Continuous tracking on.

Tracking PWA — simple mobile tracking

The Tracking PWA is simpler to operate and does not require a separate app-store installation.

  1. Open the current Tour link and enter the Tour number and surname.
  2. Select Start Tracking.
  3. Keep the tracking page open and active and the mobile device connected to the internet. Do not use flight mode.
  4. Reduce screen brightness to conserve battery power.

Tracking Android App — background tracking

Once installed on Android, this app can track while the phone is being used normally. Open the new Tour link to update its configuration, enter the Tour number and surname, then select Start Tracking.

Organiser Tracking App — Android

Allows the organiser to view and monitor entrant locations. Refer to its own Help document for detailed operation.

Field Tool — Android

Used to capture a Tour route and mark points of interest in the field. Refer to its own Help document.

Mobile tracking and network connection

Tracking depends on the app chosen and its network connection. When a device can submit reports, positions become available to Live Tracking. Background-capable apps may behave differently from the PWA during screen-off operation or temporary network loss.

Tracking PWA: Keep the page open and active with an internet connection. Do not rely on flight mode for live tracking. A mapped route is optional: the Tracking page can display entrant positions without one.

Normal event workflow

  1. Upload the active Tracking event from the desktop Tracking card.
  2. Confirm that only the required Tour tracking dates are enabled; Tracking is not enabled on rest days.
  3. Share the current Tour-specific link for the selected tracking app with each entrant. An installed app can be reused for the new Tour.
  4. Run Live Tracking during the event.
  5. Check that the selected tracking app is reporting and that entrant locations appear in Live Tracking; follow that app's own instructions for any queued records.
  6. After the event, select Event Replay and review all entrants or one entrant from the required start time.
  7. Select Return to Live when the replay review is complete.
