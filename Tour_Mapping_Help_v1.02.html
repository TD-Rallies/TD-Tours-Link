Tour Mapping Help

The Mapping page is used to build or edit the Tour route, keep waypoints in driving order, import Field Tool data, calibrate route distances, and save the map file for use in Schedule and field work.

Overview

The page has two main areas: the left panel for route controls and waypoint details, and the map area for placing, checking and editing points. Fit Route and Help are centred for quick access.

The map banner shows the current Map detail for the selected Tour day. Tour Mapping is day-based and one route per day.

Save before Schedule: Mapping keeps the working map locally while you work, but Schedule can only import a map after Save Route has created the map JSON file in the Tour Maps folder.
Normal workflow: select the correct Tour day, build or edit the map, enter waypoint details/notes, select Save Route, then import that saved map into the matching Tour day in Schedule.

Tour Workspace and map files

Admin sets one shared Tour Workspace. Inside that workspace, each Tour has its own project folder. Mapping stores Tour map files directly in:

Example folder structure
Tour projects / Cape Tour 2026 / Maps

There are no route subfolders in TD Tour.

Each time Save Route is used, Mapping creates a new versioned JSON file. The filename is based on the Tour title, day and save time.

Example:

Cape_Tour_2026_Day_1_map_2026-08-29_1045.json

The Map description is stored inside the file and shown in the Map pill with the saved version date and time. Use a short description that helps identify the version.

Mapping and Schedule

Mapping owns the Tour map. Schedule does not use the unsaved working map directly.

A map must be saved before it is available to Schedule. Select Save Route first, then use Import Mapped Route in Schedule to choose that saved map file.

If the route is changed later, save the revised map again and import the new saved version into the matching Tour day in Schedule.

Reset Mapping

Reset is a full clean-start action for the active Tour. It clears the Mapping page and removes all locally stored Mapping day routes for that Tour, including routes that Tracking would otherwise continue to display.

Before Reset proceeds, Mapping warns that all locally stored Tour day routes will be cleared. Saved map JSON files in the Tour workspace Maps folder are not deleted.

If a route is needed again after Reset, use Load Route and reopen the saved map file from the Tour workspace.

Starting a new map

When a blank route is opened, Add Next WP is already ON. Move or zoom the map to the required starting position, then click the map to place the first waypoint.

The first waypoint becomes the Start of the ordered Tour route. Continue clicking the map in driving order to add further waypoints, or turn Add Next WP off when the initial placement is complete.

Route points and order

Each route point appears as a card in the left panel and as a marker on the map. Select a card or marker before editing it or inserting a waypoint after it.

Route order matters. The saved Mapping file keeps the waypoint order, notes and distances.

Waypoints Normal Tour route points used for instructions and important route positions.
Breadcrumbs Route-shaping points used to guide the mapped road path. Breadcrumbs are not imported into Schedule.

Insert WP After Selected

Use Insert WP After Selected when an instruction point needs to be added into an existing Tour route.

First select the waypoint that comes before the new point. Select Insert WP After Selected, then click the map where the new waypoint should be added.

After the new waypoint is added, Insert mode turns off automatically.

Breadcrumbs

Breadcrumb mode is for sketching or refining the route path between important waypoints.

To add breadcrumbs at the end of the route, turn Breadcrumb ON, click the map in driving order, then turn Breadcrumb OFF when done.

To insert breadcrumbs within an existing route, first select the previous point, turn Breadcrumb ON, place the required breadcrumb points, and turn it OFF when finished.

Adding a normal waypoint automatically turns Breadcrumb mode off. This helps prevent accidental breadcrumb placement during normal route editing.

Import Field Data

Use Import Field Data to bring in data captured with the Rally Field Tool. Imported waypoints, Trip Marks, notes and Route Survey information first appear as field-reference information. They do not become part of the formal mapped route automatically.

Adding imported details to the route

  1. Select Import Field Data and load the Field Tool file.
  2. The imported points and Trip Marks appear on the map and in the Imported Field Data cards.
  3. Use Zoom, or select the imported point, to review its GPS position and note.
  4. Use Google Earth, Maps Satellite View or Street View where further location checking is useful.
  5. If the point belongs in the formal Tour route, select Add to Route.
  6. A captured waypoint keeps its Field Tool note when it is added.
  7. A Trip Mark is added as a normal Instruction waypoint and carries its captured note.
  8. Mapping inserts the new point according to its position along the route and recalculates distances.

Imported points that are not added remain field-reference information only and are not supplied to Schedule.

If the Field Data contains a Route Survey, Mapping shows it as a separate dotted reference line. It does not alter the formal mapped route, distances or OSRM routing.

Use Show / Hide to temporarily hide or restore the Route Survey. Its visibility is retained when the Mapping file is saved and reopened.

Clear Imported Field Data removes remaining field-reference data, including the Route Survey. It does not remove or change the formal mapped route.

Distance calibration

Distance CAL compares the mapped distance with an independently measured distance, a percentage correction can be applied to Tour distance values without changing the route geometry.

The calculated Error % shows the comparison. The Correction % is the value you choose to apply.

Using Distance CAL

  1. Select Distance CAL.
  2. Enter the Mapped distance.
  3. Enter the independently Measured distance, for example from the Rally Field Tool GPS odometer or a calibrated distance-measuring device.
  4. Mapping calculates the Error %.
  5. Enter the signed Correction % (+ / -) to apply.
  6. Select Apply Correction.

Example: if the mapped distance is 44.000 km and the measured distance is 44.040 km, the error is approximately +0.091%. A correction such as +0.09% can then be applied.

Mapping keeps the raw OSRM/map distance as the underlying reference. Distance calibration changes the Tour distance values only; it does not move the route or change waypoint coordinates.

Mapping and the Tour project

Mapping is part of the active Tour project. Each Tour day has its own Mapping working data.

Save Route creates a reusable versioned map file in the Tour Maps folder.

Save Project saves the complete Tour project, including Admin and Schedule data. The map itself is saved separately with Save Route in the Tour Maps folder.

Importing a saved map into Schedule

Changes made in Mapping do not alter Schedule automatically.

  1. Select the correct Tour day in Mapping.
  2. Build or edit the route.
  3. Select Save Route. This creates the map JSON file in the Tour Maps folder.
  4. Open Schedule and select the same Tour day.
  5. Select Import Mapped Route.
  6. Choose the saved map file from the Tour Maps folder.
  7. Check the imported route and save the Tour project.
Important: If you change the map again, save a new map version before importing the revision into Schedule.

Share Route

Share Route helps locate the already-saved route JSON so it can be sent to a phone or other device.

  1. Save the route first.
  2. Select Share Route.
  3. Select Open Route Folder.
  4. In the Windows file window, right-click the required JSON file and send/share it using Email or another suitable method.

Sharing a route with the Field Tool

The saved Mapping JSON can be loaded into the Rally Field Tool for Route Validation.

  1. Finish or update the route in Mapping and select Save Route.
  2. Select Share Route, then Open Route Folder.
  3. Send the required Tour map JSON to the mobile device.
  4. On the phone, download the JSON file.
  5. Open the Rally Field Tool and select Route Validation.
  6. Select Load Route to Validate and choose the downloaded map JSON.
  7. Select the waypoint where the validation run will start, then begin the validation trip.

During the run, the Field Tool compares the mapped cumulative distance with the GPS trip distance recorded at each waypoint.

Using Mapping with Schedule

A Tour map is available to Schedule only after it has been saved with Save Route. The saved file is then imported using Import Mapped Route.

The import uses ordered waypoints, notes and mapped distances. Breadcrumbs are not imported because they are Mapping support points only.

Mapped route ownership

Waypoints imported from Mapping remain owned by Mapping for physical route structure and mapped distance.

  • Mapped distances are locked in Schedule.
  • Mapped waypoints must be moved or deleted in Mapping.
  • After changing the route, save the revised map and import it into Schedule again.

Schedule additions

Schedule may contain additional instruction rows that are not part of the mapped route.

  • These rows belong to Schedule.
  • They can be edited or deleted in Schedule.
  • They are preserved when the mapped route is imported again.
  • Rows with entered distances are merged into route-distance order; blank-distance rows remain at the end.
