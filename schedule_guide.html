Schedule — Tour Roadbook Guide

Overview

The Schedule page is used to prepare the Tour roadbook for each Tour day. It can be built manually, or populated from a route prepared in Mapping.

The Tour Schedule is intentionally simple. It does not use rally speeds, timings, controls, speed groups or scoring. In the normal view the working columns are #, KM, MILES, INSTRUCTION and TURN. The optional Tulip view replaces the visible TURN column with a graphical Tulip column between MILES and INSTRUCTION.

The page includes a Normal/Compact button. This changes the screen scale only.

Key steps

  • Select the required Tour day.
  • Import a mapped route, or build the roadbook manually.
  • Add or edit Schedule-only instruction rows.
  • Enter distances in kilometres; miles are calculated automatically.
  • Use the row checkbox to hide complete rows from print where required.
  • Use the TURN column for optional turn abbreviations, or select Tulip for a graphical roadbook.
  • Save the Tour project regularly.
  • Print the current Tour-day roadbook when ready.

Rows

Select ADD ROW to add Schedule-only instruction rows.

Row types

  • Instruction — one normal instruction row.
  • Instruction x 5 — adds five instruction rows together.

Column 1 — row number, gear and print checkbox

The first column contains the row number and row gear menu. It also contains the row-level print checkbox.

  • The row number shows the current Schedule sequence.
  • The gear opens the row menu for insert/delete actions.
  • The checkbox hides the entire row from Schedule print when selected.
  • The print-hide state is retained when the Tour is saved and reopened.

KM

The KM column is the working distance column. Distances are displayed to two decimal places.

  • A newly added row starts with a blank distance and an orange ring.
  • The orange ring clears once a real distance has been entered or confirmed.
  • A blank distance remains genuinely blank through page changes and save/reopen.
  • A genuine 0.00 remains a valid distance and is not treated as blank.
  • If a distance goes backwards compared with the previous positioned row, it is flagged as an error and should be corrected.

MILES

The MILES column is derived automatically from the KM value.

Miles = KM × 0.621371

  • Miles are displayed to two decimal places.
  • The Miles value is not separately stored or edited.
  • If KM is blank, Miles remains blank.
  • If KM is 0.00, Miles displays 0.00.

Instruction

Use the Instruction column for the roadbook wording associated with each route point or manually added Schedule row.

Mapped instruction text is imported from Mapping. Once the route has been imported, then Schedule is the working place for roadbook wording, edits made will not be overwriiten by a later import.

TURN

The TURN column provides the standard abbreviations:

  • TL — Turn Left.
  • TR — Turn Right.
  • CSO — Continue Straight On.
  • B/L — Bear Left.
  • B/R — Bear Right.

Click the TURN header to include or exclude the complete TURN column from print. When the TURN header is shown in red, that column will not be printed.

Tulip roadbook option

Select Tulip at the top of Schedule when a graphical roadbook is required.

  • Tulip mode hides the visible TURN column and adds a TULIP column between MILES and INSTRUCTION.
  • The Schedule rows become taller so the route diagrams and icons remain legible.
  • Select Tulip again to return to the normal compact TURN view. Existing TURN information is retained.
  • Tulip mode is remembered when the page is reopened.

Adding or editing a Tulip

  • Click the Tulip cell for the required Schedule row. This is available on both Schedule-only rows and rows imported from Mapping.
  • Select the required route diagram in the floating Tulip window.
  • For a roundabout, select Configure Roundabout, choose the number of branches and the required exit, then select Done.
  • Select Icons to add road-sign or service icons. Choose the required quadrant directly on the preview or with the TL/TR/BL/BR buttons.
  • Select Apply in the Icons view to return the icon changes to the Tulip preview.
  • Select the main Apply button to apply the completed Tulip to the Schedule row.
  • Remove Tulip clears the Tulip from that row while keeping the editor open so another diagram can be selected.

The Tulip window can be dragged by its header, allowing the underlying Schedule row to remain visible while the diagram is being prepared.

Tulips on Mapping-owned rows

A Tulip is Schedule presentation data. It can therefore be added to a Mapping-owned row without changing Mapping ownership of the waypoint position, route sequence or mapped distance.

Using Mapping with Schedule

Mapping and Schedule use the same Tour Workspace. Tour map files are stored directly in the active Tour project's Maps folder.

Importing a mapped route

  • Select the correct Tour day in Schedule.
  • Select Load, then Import Mapped Route.
  • The file picker opens in the Tour Maps folder.
  • Select the required Tour map file.

Schedule imports mapped waypoints, their instruction notes and mapped distances. Mapping breadcrumbs are not imported because they are route-shaping points rather than roadbook rows.

Mapping-owned rows

Rows imported from Mapping remain Mapping-owned for their physical route identity and mapped distance.

  • The mapped distance is locked in Schedule.
  • A Mapping-owned row cannot be deleted in Schedule.
  • To move, add or remove a mapped waypoint, return to Mapping, make the change, save the map and re-import it.

Schedule-owned rows

Additional manual instruction rows may be added directly in Schedule.

  • Schedule-only rows remain editable in Schedule.
  • They are retained when a mapped route is imported again.
  • Rows with real distances are merged into the final sequence by distance.
  • Rows with blank distances remain at the end in their existing order.

Mapped Start

The mapped Start at 0.00 km is the authoritative first route row after Mapping import. A duplicate Schedule Start is not retained.

Re-importing a revised map

When a revised map is imported:

  • new mapped rows replace the previous mapped rows;
  • existing Schedule-only instruction rows are retained;
  • the combined roadbook is reordered by distance;
  • blank-distance Schedule rows remain at the end.

Deleting rows

  • A Schedule-owned instruction row can be deleted in Schedule.
  • A Mapping-owned row cannot be deleted in Schedule.
  • To remove a mapped waypoint, delete it in Mapping, save the revised map and re-import.

Day selection

Use the Day selector at the top of the page to choose which Tour day is being viewed and edited.

  • Selecting another day loads that day's Schedule data.
  • Blank unfinished distances remain blank when changing days.
  • Each day has its own mapped route reference and Schedule rows.

Save and Load

Save and Load use the common Tour project storage.

  • Save writes the current Tour project to the active Tour folder.
  • Load Tour opens a previously saved Tour project.
  • Import Mapped Route imports a saved map from the Tour's Maps folder.
  • Loading a Tour replaces the currently active Tour data.

Print

Select Print to print the current Tour-day roadbook.

  • KM and MILES are printed as separate distance columns.
  • Rows whose first-column checkbox is selected are omitted completely.
  • In normal view, the TURN column is included unless TURN has been switched off at the column header.
  • In Tulip view, Tulip diagrams are printed and the TURN column is not shown.
  • Instruction text is left aligned for roadbook readability.

Practical workflow

  1. Prepare the route in Mapping.
  2. Save the map into the Tour's Maps folder.
  3. Open Schedule for the same Tour day.
  4. Import the mapped route.
  5. Add any additional Schedule-only instruction rows.
  6. Enter their KM distances where known, distance of mapped rows can only be changed in mapping
  7. Edit the roadbook instruction wording.
  8. Check KM/Miles and TURN information, or select Tulip and add graphical instructions where required.
  9. Hide any rows that should not appear in print.
  10. Save the Tour and print the roadbook.

Mapping remains the source for physical waypoint position and mapped distance. Schedule remains the working source for the printed roadbook and Schedule-only instruction rows.
