TD Tours Overview

Introduction

TD Tours is an integrated system for organising road touring events. It brings entrant administration, route mapping, roadbook schedules and optional live tracking together in one Tour project.

The main Tour pages are:

  • Admin — set up the Tour, Tour days and entrant information.
  • Mapping — plan and save the route, waypoints and route notes.
  • Schedule — prepare the roadbook using mapped and manually added instructions, with an optional Tulip roadbook view.
  • Tracking — optionally monitor entrant progress and review recorded movement.

All core pages share the same Tour project. The active Tour, its days, entrants, maps and Schedule remain aligned as you move between pages.

Schedule can be used in the normal TURN-column format or switched to the optional Tulip format. Tulip mode replaces the visible TURN column with graphical route instructions and optional road-sign or service icons while keeping the underlying Schedule data together.

The basic workflow

1. Admin

  • Enter the Tour title.
  • Select the number of Tour days and enter the date for each day.
  • Select Tools, then Set Tour Workspace, and choose the folder where Tour projects are to be stored.
  • Select Administration, then Code.gs guide, aiding setting up Google, a once off procedure.
  • Add entrants manually or use the Google entry system to collect them online.
  • Tour numbers are assigned in Admin and remain the entrant identity used by the Tour package.
  • Use Save regularly. Save As creates a new Tour project folder including any project maps.

2. Mapping

  • Open Mapping from the Dashboard and select the Tour day being prepared.
  • Plot the route in driving order and add waypoints where instructions or route references are required.
  • Add or edit waypoint notes while planning the route.
  • Use the available map tools to refine waypoint positions and route shape.
  • Save Tour map files directly in the Tour project's Maps folder.
  • When the mapped route is ready, import it into Schedule.

Mapping owns the physical route structure and mapped waypoint positions. If a mapped waypoint is moved, added or removed, changes are made in Mapping, saved, and then re-imported into Schedule.

3. Schedule

  • Import the mapped route for the active Tour day.
  • Mapped rows are placed in route-distance order. Schedule-only instruction rows are retained and merged according to their entered distance.
  • The mapped Start at 0.00 is the authoritative first route row.
  • Use Add Row to add additional Schedule-only instructions where required.
  • A blank distance remains blank until it is entered; unfinished rows remain at the end of the Schedule.
  • Distances are shown in KM and automatically converted to MILES.
  • The row checkbox in the first column can be used to hide a complete row from print.
  • The TURN column can be used for common turn abbreviations and can be excluded from print when not required.
  • Select Tulip when a graphical roadbook is required. The TURN column is hidden and a Tulip column is shown between MILES and INSTRUCTION.
  • Click a Tulip cell to build or edit the route diagram for that row. Tulips can also be added to rows imported from Mapping.
  • Print produces the current Tour-day roadbook in the active normal or Tulip format.

4. Tracking

  • Tracking is optional and does not affect the normal Admin, Mapping or Schedule workflow.
  • The Tracking page provides the organiser with a live view of entrant positions when tracking data is being received.
  • There is also an orginisers mobile tracking app that can be used during the event
  • Recorded movement can also be reviewed later using replay functions.
  • Tracking is based on the Tour's actual day/date list, so the same Tour link can remain valid across the event.

Google form entries

TD Tours can use Google Forms and Google Sheets to automate entrant data collection. The initial Google connection is set up from the Administration card in Admin.

  • Complete the Google setup once using the Code.gs Set up guide.
  • Enter the Google Web App URL in Administration and use Save & test to confirm the connection.
  • Upload the Tour entry configuration to create or update the online entry form.
  • Share the entry link by the available sharing methods.
  • When entries have been submitted, review the Google data and select Download entry data to populate Admin.

The Google form does not assign Tour numbers. Tour numbers are assigned by Admin after the entrant data is downloaded.

Cloudflare (Traccar) link

The use of Traccar is optional but reqires a one time setup linking the tracking app to Google sheets so that entrants can be tracked via TD Tours as well as the mobile tracking app.

  • Refer to the Cloudflare guide.
  • Enter the Cloudflare URL into Traccar Connection and use Save & test

The Dashboard

The Dashboard is the main navigation and summary page for the Tour package.

  • Open Admin, Mapping, Schedule or Tracking.
  • Review entrant/Admin information and mapped route-distance summaries.
  • Open the individual help documents.
  • Use the Tour Apps section to select and share supporting app links.
  • Use Load prior Tour when an earlier saved Tour project needs to be opened.

Tour project storage

A Tour project uses one Tour workspace folder. The project file is stored at the Tour folder root and map files are stored directly in its Maps folder.

There are no Route 1 or Route 2 subfolders in the Tour package. Mapping and Schedule both use the same day-based Tour structure.

Supporting apps

The Dashboard contains the Tour Apps section for distributing mobile tracking and field-operation app links. These apps are separate from the core desktop pages. Select the required app, then use Copy, Email or WhatsApp to share its link.

Important — every new Tour needs a new shared tracking link. An app that is already installed can be reused; opening the new Tour link updates its configuration for that Tour, without reinstalling it. Each entrant must enter their Tour number and surname for the current Tour. The organiser should share the new link before tracking begins.

Traccar — Android and iOS

Traccar supports background tracking while the phone screen is off or the phone is being used for other activities. Initial installation and setup are more involved than for the other tracking apps.

  • Download and install Traccar from the device's application store.
  • In Traccar, configure Location: Highest; Distance: 500 metres; Interval: 30 seconds; Angle: Disabled / 0 degrees; and Stationary heartbeat: 60 seconds.
  • Open the current Tour link shared from Tour Apps to apply the Tour configuration.
  • Enter the entrant's Tour number and surname, then switch Continuous tracking on.

Tracking PWA — simple mobile tracking

The Tracking PWA is easier to use and does not require installing a separate store app, but the tracking page must remain open and active during the journey.

  • Open the current Tour tracking link, enter the Tour number and surname, then select Start Tracking.
  • Keep the mobile device connected to the internet and leave the Tracking PWA open and active throughout the journey. Do not use flight mode.
  • Reduce screen brightness to conserve battery power.

Tracking Android App — background tracking

Install the Android Tracking App to continue tracking while the phone is used normally.

  • Open the current Tour link to update the installed app's Tour configuration.
  • Enter the Tour number and surname, then select Start Tracking.

Organiser Tracking App — Android

Used by the organiser to view and monitor Tour entrant positions. Refer to the Organiser Tracking App's own Help for operating instructions.

Field Tool — Android

Used in the field to capture a Tour route and mark points of interest. Refer to the Field Tool's own Help for detailed guidance.

Note: A plotted or suggested route is not required for live entrant tracking. Entrant locations can be monitored without a mapped route.
