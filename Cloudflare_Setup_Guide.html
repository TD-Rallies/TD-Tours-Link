TD Tours — Cloudflare & Traccar Setup Guide

This guide is for the new custodian of TD Tours. It explains why Cloudflare is used, how to set it up once, and how to confirm that GPS records are reaching TD Tours.

Overview

Traccar Client is a free GPS tracking application for Android and iPhone. TD Tours uses a free Cloudflare Worker to relay Traccar position reports to its Google Tracking Sheet. TD Tours Tracking and shared organiser tracking apps then read that data.

There are also two alternatives: Tracking PWA supports Android and iPhone but requires the app to remain open and visible; Tracking Android App supports tracking with the screen closed during normal Android phone use.

A custodian sets up Cloudflare once. The resulting Worker can be used for future Tour events without creating a new Worker for each Tour.

1. Create a Cloudflare Worker

  1. Open Cloudflare. Create a free account or sign in.
  2. In the Cloudflare dashboard, open Workers & Pages and choose to create a Worker (the menu wording may vary).
  3. Choose the basic Hello World starting Worker.
  4. Name the Worker, for example traccar-relay.
  5. Select Deploy.

Cloudflare automatically assigns a web address to your new Worker when you first deploy Hello World. This address stays the same when you replace Hello World with the TD Tours Cloudflare.js code in Step 2.

You will open this address to test the Worker in Step 3, then copy it into TD Tours Admin in Step 4.

2. Replace Hello World with TD Tours code

  1. Open the new Worker and select Edit code or the equivalent code editor.
  2. Remove the existing Hello World JavaScript.
  3. In TD Tours, open Admin → Administration → First time setup → Open Cloudflare.js.
  4. Click in the code area, press Ctrl+A and then Ctrl+C to copy the complete Worker v0.03 code.
  5. Paste the copied JavaScript into the Cloudflare Worker editor.
  6. Find TARGET_URL. Replace its value with your own TD Tours Google Apps Script Web App deployment URL, ending in /exec.
  7. Click Deploy again to publish the replacement code.
Important: Do not leave the previous custodian's Google URL in TARGET_URL. The Cloudflare Worker must forward to the Google deployment belonging to your TD Tours installation. The second Deploy is essential.

3. Check that the Worker is running

  1. Open your deployed workers.dev address directly in a browser.
  2. It should display:
TD Tour Traccar Relay v0.03 OK

If Hello World appears instead, return to the editor and deploy the TD Tours Worker code again.

What this proves: The Cloudflare Worker is reachable. It does not yet prove that GPS data is being accepted by Google. That is checked in Step 5.

4. Connect Cloudflare to TD Tours

  1. Open TD Tours → Admin → Administration.
  2. Locate Traccar Connection (Optional).
  3. Paste your Cloudflare Worker URL and select Save & test.
  4. Close and reopen TD Tours to confirm the saved URL is still displayed.

If the message says the browser could not verify Worker health, cross-origin restrictions may be responsible. This does not by itself mean the Worker failed. Check its URL directly as described in Step 3.

5. Test the complete tracking chain

Prepare a test Tour

  1. Create a TD Tours test Tour with today's date.
  2. Add a couple of entrants with driver surnames.
  3. Open Tracking → Tracking → Upload tracking data. Complete the upload and close its card.

Configure a mobile phone

  1. Install Traccar Client on the phone.
  2. Allow the location permissions Traccar requests. Android: Open Settings → Apps → Traccar Client → Battery and select Unrestricted. iPhone / iOS: Open Settings → Privacy & Security → Location Services → Traccar Client; select Always and enable Precise Location. Enable Background App Refresh for Traccar Client where available, and do not force-close the app during tracking. Mobile settings and available functions may vary depending on phone model, operating system version and Traccar Client version.
  3. In TD Tours Home, select Traccar and share the link to the phone.
  4. Open the link; select Android or iPhone, then Configure Traccar.
  5. In Traccar Client, select Change settings if needed. Confirm the Server URL corresponds to your new Cloudflare Worker.
  6. Set Device identifier to the entrant's Tour number followed by surname, for example 12 Smith, and save.
  7. Tracking settings: For initial testing, set Distance = 0 metres and Interval = 30 seconds to confirm GPS reports are arriving. For normal Tour tracking, use Distance = 500 metres, supported by both Android and iOS. Return to the main Traccar screen.
  8. Enable Continuous tracking and open Show status to check for location reports at approximately 30-second intervals (subject to GPS reception and phone restrictions).

Confirm records reach Google and TD Tours

  1. Return to TD Tours and open Tracking → Tracking → Open tracking log.
  2. In the Google Spreadsheet, select the Tracking tab.
  3. Confirm that new GPS records arrive for the test entrant, with the expected identifier and fresh timestamps.
  4. Return to the TD Tours Tracking map and confirm that the entrant's location marker is shown.
  5. On both Android and iPhone, verify that tracking continues with the screen locked, subject to the phone’s location and background-operation permissions.

Successful end-to-end test

  • Worker URL displays the v0.03 OK response.
  • TD Tours Admin remembers the Worker URL after reopening.
  • Traccar Client shows the intended Server URL and Device identifier.
  • Fresh GPS records appear in the Google Tracking Sheet.
  • The entrant location appears on the TD Tours Tracking map.
Once all five checks pass, the connection has been tested end to end. The same Cloudflare Worker may be used for subsequent Tour events. Update the shared Tour identity when starting each new Tour; do not recreate the Worker.
