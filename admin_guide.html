Admin — Tour Setup & Entries

Overview

The Admin page is the starting point for each Tour. It creates the Tour identity, defines the Tour days and dates, manages entrant details and provides the Google Administration tools used to collect entries and support Tracking.

Quick steps

  • Enter the Tour title.
  • Select the number of Tour days and set the date for each day.
  • Set the Tour Workspace so project files can be saved.
  • Complete the one-time Google setup via the Administration card.
  • Optionally complete the one-time Cloudflare via the Administration card.
  • Upload the Tour entry configuration and share the entry form.
  • Download submitted entries or enter entrants manually.
  • Review the assigned Tour numbers.
  • Save the Tour project.

The page includes a Normal/Compact button. This changes the screen scale only.

Tour days

  • Select the number of Tour days, up to seven.
  • Enter the date for each day.
  • Dates can be non-consecutive where the Tour includes rest days or breaks.
  • The Tour date list is also used by Tracking to determine which dates belong to the event.

Control panel

  • Tour Title — enter the Tour name when creating a new project.
  • ADD ROW — adds an entrant row to the bottom of the table.
  • Save — saves the current Tour project to the selected workspace.
  • Load — loads a previously saved Tour project. Loading replaces the current project data.
  • Print — prints the entrant list.
  • Administration — opens the Administration card for entry and tracking setup.
  • Tools — provides workspace, Save As, Load and New Tour functions.

Save and Load

Admin manages the Tour project workspace. Once a workspace has been selected, each Tour is stored in its own folder.

  • Set Tour Workspace — choose the parent folder where Tour projects will be stored.
  • Save — saves the active Tour project.
  • Save As — creates a new Tour project with a new title. Existing map files are copied into the new Tour's Maps folder.
  • Load — opens a previously saved Tour project.
  • New Tour — clears the current Tour data and starts a new Tour project.

Each save advances the project issue reference shown as rXXX. If an older saved issue is loaded, normal Save is protected so that a newer project file is not accidentally overwritten; use Save As when required.

The entrant table

The entrant table can be populated manually or from Google entry data.

The Tour entrant details are:

  • Driver first name and surname.
  • Navigator first name and surname.
  • Driver mobile number.
  • Driver email address.
  • Car make/model.
  • Car year.
  • Tour number.(non editable)

Tour numbers are assigned by Admin according to the table order. The Google entry form excludes Tour numbering.

Entry row gear menu

  • Insert — insert a new row above or below.
  • Copy row — copy entrant details.
  • Paste — paste copied details into an empty row.
  • Delete — remove a row after confirmation.

When rows are inserted or deleted, the displayed sequence is updated.

Google Administration

Select Administration to open the Google interface. This is the gateway to automated entry collection and Tracking data.

The initial Google connection is a one-time setup. Use the Code.gs guide in the Administration card and complete the process carefully. Once connected, the same Google arrangement can be used for later Tours.

Setup process

  • Open Administration and select Code.gs guide.
  • Complete the Google Apps Script setup.
  • Enter the organiser mobile number where requested.
  • Paste the Google Web App URL into the setup field.
  • Select Save & test.
  • The status should change to Connected.

Entry data

After the Tour has been created in Google, the entry form can be shared with prospective entrants.

  • Upload entry data creates or updates the Tour's Google entry structure.
  • The entry form title defaults from the Tour title and can be edited before upload where required.
  • Use the available link buttons to open or share the entry form.
  • View responses opens the raw Google form responses.
  • Open entry data opens the processed worksheet ready for download.
  • Download entry data transfers the processed entries into the Admin table.

An entrant can submit more than one response. The processed Google worksheet uses the latest qualifying entry for that person.

It is good practice to review the Google entry worksheet before downloading it into Admin.

Traccar Connection (Optional)

The use of the Traccar app is optional but it requires a one time setup linking the tracking app to Google sheets via a 3rd part link - Cloudflare.

  • Refer to the Cloudflare guide.
  • Enter the Cloudflare URL into Traccar Connection and use Save & test
  • Then close and re-open the Aministration card to confirm that the URL has been retained.

Tracking configuration uses the Tour's explicit day/date list rather than a simple start-to-end date range. This allows a Tour to include rest days or non-consecutive event dates while retaining one Tour Tracking link.

The Tracking page and supporting mobile app use the Tour identity and Tour numbers created in Admin.

Printing

Admin Print, the entrant list for the Tour.

Recovery

Normal recovery should be attempted by closing and reopening the page, checking the active Tour and reloading the last saved Tour project if necessary.

Clearing browser storage or deleting Google project folders is an advanced recovery action and should only be used when normal recovery has failed and a clean restart is intended.
